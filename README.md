## Опис проєкту
Ця лабораторна робота присвячена закладенню фундаменту професійного інструментарію програмного інженера. У межах роботи реалізовано базову логіку сервісу **RenderPen** (renderpen.com), який досліджувався у Практичній роботі №1.

### Реалізований функціонал:
- `main.py`: Логіка валідації формату 3D-моделей (.glb).
- `ai_labels.py`: Функція створення інтерактивних міток (Labels) для анотування моделей (згенеровано за допомогою AI).

## Використані інструменти
- **IDE:** Visual Studio Code (у хмарному середовищі GitHub Codespaces).
- **VCS:** Git та платформа GitHub для хостингу репозиторію.
- **AI-асистент:** Windsurf (на базі Codeium) для автоматизації написання коду.
- **Розмітка:** Markdown для оформлення документації.

## Робота з Git
У ході роботи було виконано наступні операції:
1. Ініціалізація та налаштування локального репозиторію.
2. Робота з гілками: створення гілки `feature/renderpen-logic`.
3. Створення та успішне злиття (Merge) Pull Request на GitHub.
4. Використання AI для генерації фрагментів коду за текстовим описом.
